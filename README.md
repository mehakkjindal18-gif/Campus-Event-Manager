# Campus Event Manager

A single-file, dependency-light frontend prototype based on the supplied V0 prompts.

## Run
Open `index.html` directly in a browser, or serve the folder:
`python3 -m http.server 8000`

## Included
- Cinematic monochrome hero with flowing-light/particle canvas
- Scroll reveal and reduced-motion support
- 3D tilt/glare cards
- Event workflow visualization
- Functional dashboard navigation
- FAQ accordion
- Responsive mobile layout

The Google Fonts import is optional; the site falls back to system fonts if unavailable.
